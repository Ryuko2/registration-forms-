## ⚡ STEP 3: DEPLOY IN 15 MINUTES

### Quick Path (GitHub Pages):

1. **Create GitHub Repository** (3 min)
   - Go to https://github.com
   - Click "New repository"
   - Name: `lj-services-dashboard`
   - Click "Create"

2. **Upload Files** (2 min)
   - Click "uploading an existing file"
   - Drag the 3 files
   - Click "Commit changes"

3. **Enable GitHub Pages** (1 min)
   - Settings → Pages
   - Source: "main" branch
   - Save
   - Wait 2 minutes
   - URL: `https://YOUR-USERNAME.github.io/lj-services-dashboard/`

4. **Setup Azure** (5 min)
   - Go to https://portal.azure.com
   - Create app registration
   - Add your GitHub Pages URL
   - Copy Client ID
   - Add permissions
   - Grant consent

5. **Test It!** (1 min)
   - Visit your GitHub Pages URL
   - Click "Sign in with Microsoft"
   - Login
   - **You're done!** 🎉
